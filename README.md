Recurso didáctico web para introducir las derivadas en **Matemáticas Generales de 1.º de Bachillerato General**, partiendo de la **tasa de variación media** y llegando de forma progresiva a las primeras **reglas de derivación**.

## 🚀 ¿En qué consiste este recurso?

Esta web interactiva está pensada como una primera aproximación a las derivadas, con ejemplos sencillos y manipulables.

La secuencia comienza con la **tasa de variación media**, usando como ejemplo principal:

**f(x) = x² − 1**

en los intervalos **[-1, 0]** y **[1, 2]**, para interpretar cuándo una función sube, baja o cambia más deprisa.

Después se introduce la derivada como límite solo en casos muy básicos:

* función constante
* función identidad `f(x)=x`
* función cuadrática `f(x)=x²`
* función `f(x)=x²−1`

A partir de ahí, se dejan los límites a un lado y se trabaja directamente con reglas de derivación.

---

## 📋 Contenidos incluidos

* Calculadora interactiva de **tasa de variación media**.
* Representación gráfica de la función y de la recta secante.
* Explorador de la derivada en un punto mediante valores de `h` próximos a 0.
* Reglas básicas de derivación:

  * constante
  * `x`
  * potencia
  * número por función
  * suma y resta
  * producto
  * cociente
  * regla de la cadena
* Práctica guiada con ejercicios autocorregibles.
* Quiz final de repaso.
* Ficha breve imprimible para trabajar en papel.

## ⚠️ Alcance del recurso

Este material está diseñado para alumnado que se inicia en el tema.

No incluye funciones trigonométricas como seno, coseno o tangente, porque no se han trabajado todavía en el grupo. La propia web deja indicado que queda pendiente un bloque importante de funciones para cursos o momentos posteriores.

## 🌐 Publicación en GitHub Pages

Para publicar este recurso:

1. Crear un repositorio nuevo en GitHub.
2. Subir el archivo `index.html` a la raíz del repositorio.
3. Entrar en `Settings → Pages`.
4. Seleccionar `Deploy from a branch`.
5. Elegir la rama `main` y la carpeta `/root`.
6. Guardar y esperar unos minutos.

No necesita instalación de dependencias, compilación, Jekyll ni Actions.
